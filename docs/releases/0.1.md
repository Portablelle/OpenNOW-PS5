# OpenNOW PS5 0.1

This is the final planned prerelease before a stable release. It packages the
current repository, including the launch-age FTP fix from #1/#2. Public tag
`0.1` maps to native content version `00.002.038`, title ID `PPSA99082`.
The version number does not imply new console validation or stable compatibility.

## Changes since 0.0.7

- Create `/data/opennow/config` for launch-age uploads by FTP processes running
  as another user, and repair directory permissions at startup.
- Keep saved account files in the parent directory, writable only by its owner,
  with owner-only credential file permissions.
- Read `/data/opennow/config/launch-age.txt` first. Existing
  `/data/opennow/launch-age.txt` remains supported when the new file is absent.
- Bound configuration reads, reject symlinks and avoid waiting on FIFO writers.
  Invalid configuration still blocks launch rather than inventing an age.
- Explain the new configuration path and update procedure in the README.

The package retains persistent NVIDIA login, controller-driven catalog search,
video profile selection, virtual keyboard/mouse, Auto / Stereo / 5.1 / 7.1
audio selection, multichannel Opus decoding and adaptive audio buffering.

## Validation and limitations

Host streaming and protocol regressions passed with ASan/UBSan. Targeted
persistence/configuration regressions cover old directory migration, restrictive
umasks, preserved login contents and permissions, legacy fallback, invalid ages,
symlinks and FIFO inputs. The native GPU package builds on the Linux VPS and
passes its import audit. Release archives include a per-file manifest and
SHA-256 checksums.

This new build has not been installed or tested on a PS5. The FTP fix still
requires confirmation with the affected server/loader environment. Live surround
negotiation and speaker placement remain pending. Auto checks AudioOut port
capability, not physical speakers or HDMI receiver capabilities; some GFN seats
offer only stereo. Prior FPS/HDR observations do not establish new results for
this package. Native RTSP/NVST transport, a full A/V synchronization clock,
lossless audio and Atmos remain outside this build.

## Installation

Download `OpenNOW-PS5-0.1.zip`, `OpenNOW-PS5-0.1.manifest.json` and `SHA256SUMS`.
Verify checksums, close OpenNOW and retain a rollback copy before replacing the
complete `PPSA99082` folder through a compatible native homebrew directory loader.
Preserve `/data/opennow`, which contains your saved login and personal configuration.

Open the updated app once to prepare the configuration directory. Upload
`launch-age.txt` to `/data/opennow/config/`, containing your age as an integer
from 0 to 120, and ensure it is readable by the app (for example, mode `0644`).
An existing age file at the old path needs no migration unless you want to use
the new FTP location. An invalid new file will not fall back to the old age.

This is a directory package, not a retail PKG. The source archive contains tracked
sources, upstream pins and licenses. Assets exclude personal configuration,
credentials, diagnostics, captures, dumps and proprietary SDK binaries. This
project is unofficial and unaffiliated with Sony or NVIDIA; upstream and
third-party credits and licenses remain included.
